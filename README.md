# Agro Native Origins

## Descripción del Proyecto

Agro Native Origins sera una aplicación móvil desarrollada en Flutter que busca conectar directamente a productores agrícolas con consumidores, eliminando intermediarios y facilitando la compra y venta de productos agrícolas de forma rápida, segura y accesible.

## Objetivo

Desarrollar una aplicación móvil que permita:

- Publicar productos agrícolas.
- Buscar productos por categorías.
- Facilitar la compra entre productores y consumidores.
- Promover un comercio más justo eliminando intermediarios.

## Tecnologías Utilizadas

- Flutter
- Dart
- Git
- GitHub

## Cómo ejecutar el proyecto

### 1. Clonar el repositorio

```bash
git clone URL_DEL_REPOSITORIO
```

### 2. Entrar al proyecto

```bash
cd agro_native_origins
```

### 3. Instalar las dependencias

```bash
flutter pub get
```

### 4. Ejecutar la aplicación

```bash
flutter run
```

## Funcionamiento

La aplicación permitirá a los productores publicar sus productos y a los consumidores buscarlos y visualizarlos fácilmente. El proyecto se encuentra en desarrollo y las funcionalidades se irán incorporando de forma progresiva durante el hackathon.
